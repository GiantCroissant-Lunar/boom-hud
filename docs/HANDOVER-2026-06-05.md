## New shared infrastructure (in `BoomHud.Generators`)

The original review found ~25–30% copy-pasted boilerplate across the backend generators —
**this drift is exactly what let the Godot escaping bug exist** (Godot's private
`EscapeString` had silently lost `\\`/`\r`/`\t` handling vs Terminal.Gui's). It is now
consolidated into three shared classes; the divergent per-generator copies are gone:

- **`GeneratorSourceId`** — `ComputeSourceId` (sha256 drift id, backend-independent),
  `CollectNormalizedPseudoNodes`, `FormatStringArrayLiteral`. The source id is **persisted
  by consumers for drift detection**, so it must stay byte-stable — `GeneratorSourceIdTests`
  pins the exact hash for a known document. Do not change the hashing/tree-walk without a
  deliberate migration.
- **`GeneratorEmit`** — `EscapeCSharpString` (content), `CSharpStringLiteral` (quoted),
  `EscapeXml` (double-quoted attribute set: `& < > "`, no apostrophe). Routed through by
  Godot/TerminalGui/Remotion/UGui/Unity (C#) and Avalonia/Unity (XML). React `Ts`
  (single-quoted TypeScript) is intentionally left separate.
- **`ComposeEmitter`** — `AppendHelperTypes` (the `IChildVmResolver`/`DisposableAction`/
  `CompositeDisposable` boilerplate) + `CollectComponentInstances`. Each generator keeps its
  own framework-specific `Apply` body (`SetViewModel` vs `ViewModel` vs `DataContext`).

`ImageSimilarityHandler` (was a 2313-line god-file) is now `public static partial class`
across five cohesive files: `ImageSimilarityModels.cs` (DTOs),
`ImageSimilarityHandler.cs` (~460, `Execute` orchestration + findings/notes/print +
normalization), `.Scoring.cs`, `.MeasuredLayout.cs`, `.Artifacts.cs`.

## Two review claims that did NOT hold up (do not re-attempt)

The original review over-claimed two "bugs". Both were verified non-issues this session —
re-investigate before believing any future restatement of them:

1. **`RuleResolver.cs` "grandparent bug" (was flagged High).** `IsValueRow` only runs for
   horizontal containers, so `ResolveRowContainer` resolves the row via its first branch and
   **never reads `Grandparent`**. The hard-coded `null` is unreachable. Shipped as a pure
   file split + a correct-by-construction `ForChild` cleanup (no behavior change), not a bug
   fix.
2. **`FigmaColorToIrColor` "doesn't clamp P3/HDR colors > 1.0".** The `Rgba` DTO channels
   carry `[JsonConverter(typeof(PurpleMinMaxValueCheckConverter))]`, which **throws on
   out-of-range values at `FigmaDto.FromJson`** — so a channel > 1.0 never reaches the byte
   cast. Unreachable. The attempted clamp + its (un-constructable) test were reverted.

Also: `FigmaDto.cs` is already exempt from analyzers (it has a `// <auto-generated />`
header — Roslyn skips it), so no `<generated>` csproj flag is needed.

## Operational notes / gotchas for the next session

- **Verify + commit loop:** build + full suite (`dotnet test dotnet/tests/BoomHud.Tests.Unit/BoomHud.Tests.Unit.csproj -c Release`)
  before every commit. Commit **path-scoped** (`git commit -- <files>`) — the index is shared
  with concurrent agents; never broad-stage.
- **Test project is an allowlist, not a glob.** `dotnet/tests/BoomHud.Tests.Unit/BoomHud.Tests.Unit.csproj`
  `<Compile Remove>`s `Generation/**` (and a couple of `Snapshots` files) then re-includes
  specific files via `<Compile Include>`. **A new test under `Generation/` silently does not
  run until added to that include list.** (Caught this session when a new test's count stayed
  flat.) The `Cli` *source* project, by contrast, uses default globbing — new `.cs` files there
  auto-compile.
- **`TreatWarningsAsErrors` + analyzers are on.** Unused `using`s, unused private members, and
  unresolved symbols are all build errors — the build enforces refactor completeness (a missed
  call-site or a left-behind dead method fails the build).
- **husky `dotnet-format` runs on staged `.cs`** and `--verify-no-changes` the *whole* staged
  file. If a pre-existing file has whitespace debt, the commit fails until you `dotnet format`
  it (happened once with `FigmaParser.cs`).
- **Delegation:** mechanical wiring was dispatched to the `qwen` CLI
  (`qwen --approval-mode auto-edit --output-format text "<prompt>"`), with the orchestrator
  authoring correctness-critical shared code and verifying. Recurring qwen quirk on file
  splits: **it over-prunes `using`s** (removed a still-needed `System.Text.Json` once). The
  build catches it; re-add and move on. `kilo` silently dropped one task (exit 0, zero edits) —
  always check `git status` after a dispatch, never trust the exit code.
